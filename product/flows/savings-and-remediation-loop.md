# Savings and remediation loop

From spend and recommendations to a reviewable plan.

## What it is

The reading order for a savings task. It is not an automatic pipeline, and it does not apply a change by itself.

## Who it is for

Operators and support staff who need one path across the company portal and the workspace.

## How to use it

1. Start from the [dashboard](../main/dashboard.md) or [overview](../main/overview-and-governance.md).
2. Open [cost breakdown](../main/cost-breakdown.md) to see where spend sits.
3. Open [recommendations](../main/recommendations.md). Use filters. Network is a filter category, not a tab.
4. Open [activity and status](../main/recommendation-activity-and-status.md).
5. [Generate a remediation plan](../main/generate-remediation.md) only after you choose **Yes, generate the plan**.
6. Read the session and, if you have permission, use [agent chat](../main/remediation-sessions-and-agent-chat.md). Chat is not the activity log.
7. Stop at the plan. Reading the plan does not apply it to your cloud account.

[Apps and integrations](../main/apps-and-integrations.md) is where a GitHub connection would change delivery toward a pull request. Without that connection, the plan's files are the steps and the Terraform preview.

## What to expect

Switching [business unit](../main/profile-and-business-unit-switch.md) changes which accounts and recommendations you see. It does not create resources.

Company [roles](../company/roles.md) gate the list, the session, and the chat.

## Limits

Reading the plan does not apply it to your cloud account. The filter drawer's **Apply** control only filters the recommendation list.
